# Telephone Directory

####Консольное приложение-телефонный справочник на Java.

## Технологии

- Java
- PostgreSQL
- Maven
- Lombok

## Возможности

- добавление абонентов;
- добавление до 3 телефонных номеров для одного абонента;
- поиск абонентов;
- изменение данных;
- удаление абонентов;
- сортировка по фамилии и имени.

## Архитектура

Проект построен с использованием многослойной архитектуры:

- Controller
- Service
- Repository

Для связанных телефонных номеров реализовано каскадное удаление.

## Запуск

1. Перейти в расположение файла.
2. с помощью командной строки mvn compile exec:java
